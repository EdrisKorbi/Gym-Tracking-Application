### PHASE 2: Optimized Backend CRUD & DTOs ###
Status: In Progress

Backend Architecture Convention (Layered Design):
- controllers/ : Handles incoming HTTP requests and responses.
- services/ : Contains all business rules and logic.
- repositories/ : Handles direct PostgreSQL database queries.
- entities/ : Maps exactly to our database tables.
- dtos/ : Data Transfer Objects. Controls exactly what data enters the API and what the frontend is allowed to see.
- exceptions/ : Centralized, global error handling.
